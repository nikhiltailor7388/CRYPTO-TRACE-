 # CryptoTrace I4C

Automated blockchain fund-flow tracing and VASP identification for 
cybercrime investigators. Given a victim-reported crypto wallet address, 
CryptoTrace automatically retrieves public blockchain transactions, 
traces the fund flow across a bounded number of hops, matches destination 
addresses against a curated VASP/exchange label dataset with explicit 
confidence levels, flags explainable risk patterns, and generates a 
structured investigation report — replacing hours of manual explorer-hopping 
with a single input.

Built for **Smart India Hackathon 2026** — Problem Statement **SIH26183**, 
Ministry of Home Affairs / I4C, Theme: Blockchain & Cybersecurity.

> This is a hackathon prototype, not an official government tool. It does 
> not identify real-world identities, freeze funds, or replace legal process — 
> it generates investigative leads from public blockchain data only.
